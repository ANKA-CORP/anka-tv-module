# anka-tv

Our Kick client and home screen for the Samsung TV at home, as a [TizenBrew](https://github.com/reisxd/TizenBrew) module. Only for our own home.

This repo is published from a private one; don't edit it here.

Add in TizenBrew's Module Manager (GitHub): `ANKA-CORP/anka-tv-module@1.0.0`. The tag only pins the small entry files; they load the newest commit of everything else.
